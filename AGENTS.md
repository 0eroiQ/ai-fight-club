# AI Fight Club — Engineering Rules

- Follow user requirements literally and verify against references.
- Do not improvise product behavior, simplify requested functionality or change unrelated code without approval.
- Present alternative designs as proposals, not unapproved implementations.
- Separate scripted demo responses from real provider replies and verified test results.
- Do not treat agent consensus as proof of correctness.
- No production deployment, GitHub merge, credentials disclosure or paid API calls without explicit approval.
- Test changes and honestly report what was not tested.
